**Time:** 20–30 minutes · **Focus:** slices and memory ownership

JavaScript's `array.slice()` makes a shallow copy. Go's `slice[a:b]` creates a **view** over the existing underlying array. That difference matters when building a queue.

## Shared storage

~~~go
jobs := []string{"a1", "b2", "c3", "d4"}
pending := jobs[1:3]

pending[0] = "x9"             // also changes jobs[1]
pending = append(pending, "e5") // can overwrite jobs[3]
~~~

A slice has a length and capacity. When `append` fits within capacity it may reuse the underlying array; otherwise it allocates a new one. Never assume `append` always copies.
