**Time:** 20–30 minutes · **Focus:** streams, structs, decoding

Our running project is a small job-processing service. The first input format is **JSON Lines (NDJSON)**: one independent JSON object per line, rather than one array containing all objects.

~~~json
{"job_id":"a1","status":"queued"}
{"job_id":"b2","status":"failed"}
{"job_id":"c3","status":"queued"}
~~~

## Read an event at a time

~~~go
package main

import (
    "bufio"
    "encoding/json"
    "fmt"
    "log"
    "strings"
)

type JobEvent struct {
    JobID  string `json:"job_id"`
    Status string `json:"status"`
}

func main() {
    input := `{"job_id":"a1","status":"queued"}
{"job_id":"b2","status":"failed"}
{"job_id":"c3","status":"queued"}`

    scanner := bufio.NewScanner(strings.NewReader(input))
    for scanner.Scan() {
        var event JobEvent
        if err := json.Unmarshal(scanner.Bytes(), &event); err != nil {
            log.Fatal(err)
        }
        fmt.Println(event.JobID, event.Status)
    }
    if err := scanner.Err(); err != nil {
        log.Fatal(err)
    }
}
~~~

Notice three Go-specific behaviours:

1. `for scanner.Scan()` is a condition-only `for` loop. Each call advances to the next line and returns `true` while it has a token.
2. `scanner.Bytes()` is the current line's raw bytes. It is **not** automatically assigned to the struct.
3. `json.Unmarshal(data, &event)` decodes the bytes **into** `event`. The `&` passes the address of the struct, so Unmarshal can modify it.
