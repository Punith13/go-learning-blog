## Exercise: implement the function

Use this fixture:

~~~json
{"job_id":"a1","status":"queued"}
{"job_id":"b2","status":"failed"}
{"job_id":"c3","status":"queued"}
~~~

Return `StatusCounts{"queued": 2, "failed": 1}` for valid input. If the second line is `{"job_id":`, return an error containing `line 2` that still exposes the original `*json.SyntaxError`.

## Test it

Create `events_test.go` next to `events.go`:

~~~go
package jobprocessor

import (
    "encoding/json"
    "errors"
    "reflect"
    "strings"
    "testing"
)

func TestCountStatuses(t *testing.T) {
    tests := []struct {
        name string
        input string
        want StatusCounts
        bad bool
    }{
        {
            name: "valid",
            input: "{\"status\":\"queued\"}\n{\"status\":\"failed\"}\n{\"status\":\"queued\"}",
            want: StatusCounts{"queued": 2, "failed": 1},
        },
        {
            name: "invalid line 2",
            input: "{\"status\":\"queued\"}\n{\"status\":",
            bad: true,
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            got, err := CountStatuses(strings.NewReader(tt.input))
            if tt.bad {
                if err == nil || !strings.Contains(err.Error(), "line 2") {
                    t.Fatalf("expected line 2 error, got %v", err)
                }
                var syntax *json.SyntaxError
                if !errors.As(err, &syntax) {
                    t.Fatalf("expected wrapped syntax error, got %v", err)
                }
                return
            }
            if err != nil || !reflect.DeepEqual(got, tt.want) {
                t.Fatalf("got %v, %v; want %v", got, err, tt.want)
            }
        })
    }
}
~~~

**Acceptance:** `go test -v ./...` passes. The malformed-record test must preserve the original error type.

**Hint:** Use `bufio.NewScanner(r)`, `json.Unmarshal`, and `fmt.Errorf("line %d: %w", n, err)`. Check `scanner.Err()` after the loop.

**Stretch:** Add a reader that fails partway through, and verify the failure propagates rather than reporting partial success.
